Changelog

What's new in mach.notch — every change, in order.

Unreleased Coming soon v2.0

New features

  • Obsidian Sync — Notes now write to your Obsidian vault. Enable in Settings → Shelf → Notes, pick your vault folder.
  • Teleprompter Pro — Full-featured teleprompter with countdown, mic monitoring, hover-to-pause, keyboard shortcuts, and AI text assist (refine / summarise / draft via Ollama).
  • Browser Extension — Safari web extension lets the notch control media playing in the browser, including SoundCloud metadata.
  • Habit Tracker — Daily habit tracking with streaks, progress rings, and persistent history.
  • Pomodoro — Focus timer with work / break intervals and notch-integrated controls.
  • Clipboard — Clipboard history surfaced directly from the notch.
  • Local API Server — HTTP + WebSocket server for external integrations. Powers the notchctl CLI and browser extension.
  • App Intents & URL Scheme — Siri Shortcuts integration + machnotch:// URL scheme for automation.
  • AI Subsystem — AIManager + AIProvider protocol with Ollama backend.

UI & animations

  • Wider layout — Notch expanded from 740 pt to 860 pt for better spacing.
  • Unified animations — Content and shell now animate together, with interruptible open/close and spring-tuned choreography.
  • Refined header — Better padding, alignment, and a more compact tab bar.
  • Improved gestures — Pan gestures are disabled when interacting with scrollable content.

Bug fixes

  • Horizontal bounce — Fixed a visual glitch on closing due to stale phase checks in NotchSizeCalculator.
  • Battery layout hijack — Battery expansion no longer stretches the Music plugin to 640 pt.
  • Cmd+Tab squish — The open notch no longer shrinks to closed height when switching apps.
  • Music timeline — duration and currentTime were not mapped; timeline no longer stuck at 0.
  • External display — Notch now appears on external non-notch displays when "Show on all displays" is enabled.
  • Shelf drag & drop — Dragging files out of the shelf no longer fails due to missing selection context.
  • Accessibility prompts — Removed aggressive TCC prompts on launch and settings load.

Performance

  • Background execution leaks — Fixed CPU burn when the notch is closed in the Teleprompter and Music plugins.
  • Timeline gating — Music controls switch to static layout when closed (no 60 fps background timer).
  • Background service backoff — Battery and Bluetooth polling pauses when the notch is closed.

Architecture

  • Plugin system — Monolithic singletons replaced by a plugin-first DI architecture. Every feature is a NotchPlugin.
  • 300+ .shared sites removed — Views use @Environment or init injection throughout.
  • @Observable everywhere — Migrated from ObservableObject/@Published to Swift 5.9 @Observable.
v1.3.0 Released

Foundation

  • Bazel CI — All builds and tests now run through Bazel. Xcode removed from the hot CI path.
  • mach-mono monorepo — machNotch merged into the mach-mono monorepo alongside mach.brief and shared packages.
