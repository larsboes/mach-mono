# Agent workflows

Reusable procedures for agents working in `mach-mono`.

Before running a workflow, read:

1. `AGENTS.md`
2. `repo.yaml`
3. `docs/README.md`
4. Any relevant product instructions such as `Apps/machNotch/CLAUDE.md`

Workflows should describe repeatable steps. Keep durable repo facts in `repo.yaml` and product status in `docs/prds/`.
